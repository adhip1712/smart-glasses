# Visionary Nexus – YouTube Skip Helper

This optional Chrome extension clicks **only YouTube's own visible, enabled Skip Ads button** when YouTube makes it available.

## Install in Chrome
1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Select **Load unpacked**.
4. Choose this folder: `browser-extension/youtube-skip-helper`.
5. Reload the YouTube tab opened by Visionary Nexus.

## Limits
- It cannot skip non-skippable ads or make the Skip button appear sooner.
- It does not block ads, alter ad playback, or bypass YouTube's ad system.
- YouTube may change its page controls, so this helper may need maintenance.
- The extension runs on YouTube pages only. It does not access Visionary Nexus or other sites.

If Chrome shows the Skip button, the extension attempts to click that native control automatically. Otherwise it leaves playback untouched.
