# =========================================================
# VISIONARY NEXUS - ML / COMPUTER VISION EXTRAS
# =========================================================
#
# These are SEPARATE from backend/requirements.txt on purpose: the FastAPI
# backend, the database, authentication and every existing feature work without
# any of this. Install these only to enable webcam object detection.
#
#   Windows   .venv\Scripts\pip install -r requirements-ml.txt
#   Linux     .venv/bin/pip install -r requirements-ml.txt
#
# CPU-ONLY TORCH (recommended for a laptop with no NVIDIA GPU, saves ~2 GB).
# Install torch first, then this file:
#
#   Windows   .venv\Scripts\pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#             .venv\Scripts\pip install -r requirements-ml.txt
#
# ---------------------------------------------------------
# OPENCV: use the DESKTOP build (opencv-python), NOT the headless one
# ---------------------------------------------------------
#
# The standalone demo opens a window titled "Visionary Nexus" with cv2.imshow.
# `opencv-python-headless` ships OpenCV built with `GUI: NONE`, so imshow exists
# as a symbol but raises when called:
#
#     cv2.error: OpenCV(5.0.0) ... The function is not implemented.
#     Rebuild the library with Windows, GTK+ 2.x or Cocoa support.
#
# Ultralytics itself requires opencv-python (not the headless build), so the
# desktop package below is also the one the rest of the ML stack expects.
#
# BOTH packages install into the same `cv2` directory, so they must never be
# installed together - whichever was installed last silently wins. If a headless
# build is already present, remove it first:
#
#   Windows   .venv\Scripts\pip uninstall -y opencv-python-headless opencv-contrib-python-headless
#             .venv\Scripts\pip install -r requirements-ml.txt
#
# Verify what Python actually imports afterwards:
#
#   .venv\Scripts\python -m ml.doctor
#
# HEADLESS SERVER / CI (no display, no window needed):
# the backend only ever uses cv2.imencode, so a server may substitute the
# headless build. Do that deliberately, not by default:
#
#   .venv\Scripts\pip uninstall -y opencv-python
#   .venv\Scripts\pip install opencv-python-headless
#
# The demo then prints "NO WINDOW" and keeps running headless instead of
# crashing, and the /api/vision/* endpoints are unaffected.
#
